# How to Contribute

We're always looking for people to help make ReadAIrr even better, there are a number of ways to contribute.

For current project context, start with the [ReadAIrr documentation](https://readairr.com/docs/) and open a focused issue or pull request in this repository.

## Documentation

Documentation updates should keep user-facing ReadAIrr behavior current while preserving inherited Readarr compatibility names where the code still depends on them.

## Development

Please describe the change, include relevant tests, and call out any migration or deployment impact in the pull request.
